The Perceptron Learning Rule

Read through the four examples below, then use the interactive simulator at the bottom of this page to practice the calculations yourself. Answer the reflection questions as you go.

1. The Core Idea

A perceptron is the simplest artificial neuron. It takes inputs, multiplies each by a weight, sums them up (plus a bias), and passes the result through a step function to produce an output of 0 or 1.

Prediction Formula

z = (w1 * x1) + (w2 * x2) + ... + (wn * xn) + b y_pred = 1 if z >= 0, else 0

The Learning Rule

This is how the weights get updated after each training example:

wi_new = wi_old + η * (y_true - y_pred) * xi b_new = b_old + η * (y_true - y_pred)
  • η (eta): Learning rate, a small positive number (e.g., 0.1)
  • y_true: The correct label
  • y_pred: What the perceptron guessed
  • (y_true − y_pred): The error — the engine driving the learning process
Key Idea: If the perceptron predicts correctly, y_true − y_pred = 0, meaning no changes occur. Weights are updated strictly when the model makes an error.

2. Worked Example: The AND Gate

Inputs x1, x2 ∈ {0, 1}, target y = x1 AND x2, starting weights w1 = 0, w2 = 0, b = 0, learning rate η = 1.

x1x2y (AND)
000
010
100
111

Stepping through the first epoch: the very first example (0,0) is misclassified (z = 0, which counts as predicting 1), so the bias drops to −1. The next two examples are now classified correctly and cause no change. The last example (1,1) is misclassified, which pushes w1 and w2 up to 1 and the bias back to 0. After a second epoch, the weights settle at values like w1 = 1, w2 = 1, b = −1, which correctly implements AND.

3. Why It Fails: The XOR Problem

Same setup, but the target is XOR:

x1x2y (XOR)
000
011
101
110

No matter how many epochs you run, the weights never settle on a solution that classifies all four points correctly. Try plotting the four points: the two points labeled 1 sit diagonally from each other, and so do the two points labeled 0. A perceptron can only draw a single straight line to separate two classes, so it cannot separate them.

Takeaway: A single perceptron can only learn functions that are linearly separable. This limitation is precisely why modern architectures stack perceptrons into multi-layer neural networks.
